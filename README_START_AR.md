## ترتيب التركيب
1. Supabase > SQL Editor: شغّل ملفات مجلد `supabase/run-in-order` بالترتيب (1 ثم 2 ثم 3). الأول فقط إن لم تشغّل `school_years` سابقاً. شغّل كل ملف مرة واحدة.
2. GitHub: ارفع محتويات هذا المجلد (دون node_modules ودون .env).
3. Cloudflare: ينشر وحده. اسم Worker في wrangler.jsonc هو sportsuivi01: غيّره إن كان اسم مشروعك مختلفاً.
