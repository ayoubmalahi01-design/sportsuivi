## ما لم يتم إثباته
- لم تُنفّذ ترقية SQL في قاعدة المستخدم.
- لم ينجح تثبيت npm في بيئة العمل بسبب انقطاع الوصول إلى registry؛ لم يتم تنفيذ build.
- لم يتم النشر إلى Cloudflare من هذه البيئة.
- لم يكتمل بعد نظام الموافقات متعدد المؤسسات ولا اختبار RLS الشامل بحسابات منفصلة.
- الترجمة الأساسية موجودة لكن يلزم اختبار كل صفحة وإكمال أي نصوص متبقية.
