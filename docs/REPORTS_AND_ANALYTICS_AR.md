# تقارير Sport Performance — الإصدار 1.3.1

## قاعدة البيانات والتقارير
تحتوي صفحة «ورقة التلميذ والتقارير» على تقرير المؤسسة/المجموعة وملف متابعة فردي. التقارير تعتمد السنة الدراسية المختارة في التطبيق.

### ملف Excel الشامل
يتم تنزيل مصنف Excel متوافق بصيغة SpreadsheetML 2003 (`.xls`) ويحتوي أوراقاً مستقلة:
1. **ملخص التلاميذ:** رقم واسم التلميذ، الحضور، التأخر، أنواع الغياب، آخر وزن، الطول، IMC، تغير الوزن بالكيلوغرام ونسبته مقارنة بأول وآخر قياس في السنة المحددة.
2. **نتائج الاختبارات:** كل نتيجة تاريخية لكل اختبار، النتيجة الخام، الوحدة، النقطة، وتحويلات الاختبارات الأساسية.
3. **القياسات وIMC:** جميع قياسات الوزن والطول وIMC المحسوبة لكل سجل.
4. **الحضور والغيابات:** جميع سجلات الحضور والغياب والتاريخ والحصة.

### ملف Excel الفردي
يتضمن ملخص التلميذ، وسجل نتائجه في كل اختبار، وسجل قياسات الوزن والطول وIMC، وسجل الحضور والغياب.

## التحليلات داخل التطبيق
- رسوم مستقلة لمتوسط المجموعة لكل اختبار حسب تاريخ إجرائه.
- منحنى وزن المجموعة من القياسات المسجلة.
- منحنى وزن فردي لكل تلميذ.
- منحنى مستقل لكل اختبار في الملف الفردي، مع عرض جميع النتائج وتواريخها.
- فرق الوزن بالكيلوغرام ونسبة التغير بين أول وآخر قياس ضمن الفترة المعروضة.
- الملاحظات تبقى داخل التطبيق ولا تُصدّر إلى Excel.

## تحويلات الاختبارات
- **Navette 20 m:** يحسب مستوى السرعة من 8.5 km/h بزيادة 0.5 km/h لكل palier، ثم يحول إلى m/s، ويحسب المسافة التراكمية وفق جدول مراحل بروتوكول 20 m ذي عدد الأشواط: 7، 8، 8، 8، 9، 9، 10، 10، 10، 11، 11، 12، 12، 13، 13، 13، 14، 14، 15، 15، 16. تختلف المسافة إذا كان التسجيل الصوتي المستخدم يتبع جدول أشواط آخر؛ يجب أن يطابق البروتوكول الفعلي.
- **Pompes وAbdos:** عند اعتماد اختبار الدقيقة الواحدة، يعرض التطبيق التكرارات/الدقيقة، والتكرارات/الثانية، ومتوسط الثواني لكل تكرار.
- لا يتم إنشاء درجات BARÈME تلقائياً؛ تُدخل الإدارة السلم الرسمي بنفسها.

## الخصوصية
الملاحظات وكراس المدرب الخاص غير مدرجين في ملفات Excel. لا يحتوي هذا التحديث على أوامر SQL لتعديل قاعدة البيانات.

## التحقق
لم يمكن تنفيذ `npm run build` في بيئة إعداد الملف لأن حزم المشروع غير متاحة في ذاكرة npm المحلية وتعذر الوصول إلى مستودع الحزم. لذلك يجب عدم اعتبار هذا الأرشيف بناء إنتاجياً مُختبراً حتى ينجح التثبيت والبناء واختبار الاتصال بمخطط Supabase الفعلي.
