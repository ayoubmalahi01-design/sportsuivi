# Sport Performance — النسخة المحسّنة

هذه نسخة مصدر محدّثة من التطبيق، مبنية على مشروع Sport Performance المرسل سابقاً، مع الحفاظ على بنية التطبيق الحالية وعدم تنفيذ أي تعديل على قاعدة Supabase.

## أهم التعديلات
- إضافة زر تثبيت التطبيق من شاشة الدخول وداخل التطبيق، مع إرشادات Android وiPhone.
- تحديث Service Worker إلى v4: لا يعيد صفحة HTML عند طلب ملف JavaScript/CSS، ولا يخزّن استجابات Supabase أو المصادقة.
- إصلاح استعمال setter غير معرّف في تدفق بدء الحصة وإنهائها.
- إضافة زر للإدارة لإضافة الاختبارات الأساسية الثلاثة: Navette 20 m (Léger)، Pompes، Abdos، دون إنشاء BARÈME أو درجات تلقائية.
- إدخال BARÈME يظل يدوياً من الإدارة، مع دعم اللصق من Excel/CSV أو JSON.
- عند إدخال نتيجة Navette كرقم palier، يعرض التطبيق سرعة المرحلة وفق الصيغة المرجعية 8.5 + 0.5 × (palier - 1) km/h، ويحوّلها إلى m/s بالقسمة على 3.6.
- Pompes وAbdos: الاختبار مضبوط على 60 ثانية؛ يعرض عدد التكرارات، تكرار/دقيقة، تكرار/ثانية، ومتوسط ثانية/تكرار.
- الحفاظ على صفحة IMC وقياسات الوزن والطول الموجودة.

## إعداد Supabase قبل البناء
ملف `config.js` يحتوي مرجع المشروع المعروف `lcsbwwqfeuangmuxlefq`، وقد أُعيد استعمال Publishable key العام الموجود في إعدادات النسخة السابقة، دون إدراج service_role أو أي كلمة مرور. لا تضع أبداً `service_role` أو كلمة مرور قاعدة البيانات في التطبيق.

يمكن بدلاً من ذلك تجاوز الإعدادين بمتغيري البيئة في إعدادات البناء:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

## البناء المحلي
يتطلب Node.js 20 أو أحدث واتصالاً بمستودع npm أول مرة:

```bash
npm install
npm run build
```

ينتج البناء مجلد `dist/`. إعداد `wrangler.jsonc` ينشر `dist` كـ Workers Static Assets:

```bash
npx wrangler deploy
```

## تنبيه قاعدة البيانات
لم يتم تشغيل أي SQL ولم تُحذف أو تُعدّل أي بيانات. يجب مطابقة أسماء الجداول والأعمدة في التطبيق مع مخطط Supabase الفعلي قبل اعتبار الربط السحابي نهائياً. لا تشغّل ملفات SQL القديمة أو ملف الإضافات لمجرد وجودها داخل المشروع.

## حدود التحقق
تم فحص تركيب JSX/JavaScript بواسطة TypeScript transpiler دون أخطاء تركيب. لم يمكن تثبيت حزم npm في بيئة إعداد الملف (الحزم غير موجودة في cache المحلي)، لذلك لم يُنفّذ `npm run build` ولم يتم الادعاء بأن هذا ZIP نسخة بناء إنتاجية جاهزة للنشر مباشرة.
